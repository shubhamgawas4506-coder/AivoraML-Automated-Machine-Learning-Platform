Frequently asked

Know what you are running.

Direct answers about the current product, its local workflow, and where your engineering responsibility begins.

Does my dataset leave my machine?

In the standard local setup, your browser sends the file to the AivoraML API process running on your machine. If you expose or deploy that API elsewhere, data follows the network and storage configuration you create.

Which file formats can I upload?

The upload interface accepts CSV, Excel, JSON, and Parquet files. Actual parsing support depends on the Python dependencies installed with the API.

Which machine learning problems are supported?

The current training workflow focuses on tabular classification and regression. AivoraML only runs candidate algorithms available in the installed environment.

Do I need an account or subscription?

No account is required for the local build. There is also no managed AivoraML cloud subscription represented on this page.

Can AivoraML deploy my model for me?

AivoraML can export the fitted pipeline and expose an API surface for integration. One-click managed cloud deployment is not offered by the current build, so deployment security, scaling, and monitoring remain yours.

What is included in the guided demo?

The demo is an explicitly labelled sample project that lets you explore the workflow without supplying a file. Its values are examples and should not be treated as results from your data.
